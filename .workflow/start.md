# start.md — 프로젝트 핵심 정보

> 원천 문서: [docs/WORK_ORDER.md](../docs/WORK_ORDER.md) v1.0. 이 문서는 그 요약이며, 충돌 시 WORK_ORDER §2(BR-01~15)가 우선한다.

- 프로젝트명: 비자앤잡(Visa&Job) 홈페이지 — 폐쇄형 중개 플랫폼
- 유형: 소프트웨어(웹)
- 작성일: 2026-11-15
- 운영 주체: 코리아비자 행정사사무소 + 비자앤잡 유료직업소개소

## 1. 한 줄 설명
국내 체류 외국인 구직자·구인기업·지역 직업소개소의 의뢰를 **운영자(행정사·직업소개소)가 접수하는 창구**. 당사자끼리 직접 만나지 않고, 블라인드 정보와 운영자 검증을 거쳐 매칭·면접·체류자격 변경까지 이어지게 한다.

## 2. 배경과 문제 정의
- 문제: 외국인 구직자는 자기 비자로 어떤 일을 할 수 있는지 모르고, 기업은 채용 가능한 체류자격을 모른다. 직거래 시 불법 취업·소개요금 분쟁·개인정보 노출 위험이 크다.
- 기존 방식의 한계: 공개 구인 게시판은 연락처를 노출하고 체류자격 검증이 없다. 행정사 업무와 직업소개가 분리되어 전환(E-7-4 등) 설계가 끊긴다.
- 근거: WORK_ORDER §1, §16 / 개정 직업안정법(12월 10일 시행) 구인자 신원 검증 의무 — https://lawl.co.kr/brand/columnView.html?idx=1241

## 3. 목적과 성공 기준
- 목적: 비자 진단 → 구직 등록 → 운영자 검증 → 블라인드 추천 → 면접 → 계약 → 체류자격 변경 수임의 흐름을 지원하는 웹과 내부 관리 시스템.
- 완성 조건: WORK_ORDER §14 각 Phase 완료 기준 + §15 필수 테스트 11개 통과. BR-01~15 위반 0건.
- 제약: Next.js 15 / TypeScript strict / PostgreSQL(서울 리전 전제) / Prisma / Auth.js / next-intl 6개 언어. 법령 수치 하드코딩 금지(BR-12). 법무 미확인 기능은 플래그 기본 off(§16).

## 4. 대상 사용자
| 코드 | 사용자 | 상황·목표 |
|---|---|---|
| SEEKER | 구직 외국인 (F-4·H-2·D-10·E-7·E-9 등) | 모바일, 한국어 미숙. 내 비자로 가능한 일을 찾고 싶다 |
| EMPLOYER | 구인기업 (제조·농축산·요양 등) | 채용 가능한 외국인 비자를 모른다. 검증된 인력을 원한다 |
| AGENCY | 지역 직업소개소 | 비자 업무만 의뢰 |
| STAFF_PLACEMENT / STAFF_VISA / ADMIN | 내부 직원 | 리드·구직자 검증, 추천, 체류 사건 관리 |

## 5. 흐름
1. 공개 페이지에서 비자 진단·점수 계산 (유입)
2. 간편 등록 또는 정식 위저드(Step 0~7) → 트랙 분류(JOB_MATCH / FUTURE_POOL / CONSULT_ONLY / 등록 불가)
3. 직원 상담·검증 → 등급 B→A→S
4. 구인 리드 수집(C) → 전화(B) → 구인신청·검증(A) → 블라인드 공고
5. 구직자 면접 신청 / 기업 블라인드 후보 열람·면접 요청 → 추천 원장 기록
6. 면접 확정 시 건별 실명 제공 동의 → 근로계약 → 체류자격 변경 수임
