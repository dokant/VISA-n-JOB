## 1. Начните с проверки визы

Выберите визу, регион и отрасль, чтобы увидеть справочный результат по критериям, опубликованным административным агентом.
Если критерии ещё не опубликованы, результат будет «Требуется проверка», и мы предложим оставить заявку на консультацию.

## 2. Быстрая регистрация

Начать регистрацию можно, указав только язык, визу, регион и номер мобильного телефона.
Остальные данные можно заполнить позже, шаг за шагом.

## 3. VISA n JOB связывает вас

Сотрудник VISA n JOB проверяет указанные вами данные.
Компании видят только обезличенную информацию — без вашего имени и контактов.
