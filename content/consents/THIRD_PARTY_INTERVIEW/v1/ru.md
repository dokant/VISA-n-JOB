# Согласие на передачу имени работодателю, проводящему собеседование (по каждому собеседованию)

[전문가 검토 필요] (Требуется проверка эксперта) Этот текст согласия — проект; он будет утверждён после юридической проверки.

VISA n JOB просит это согласие отдельно для каждого подтверждённого собеседования. Если вы согласны, ваше имя получит только работодатель этого собеседования.

- Получатель: один работодатель, который проводит это собеседование (название работодателя вам сообщит сотрудник VISA n JOB вместе с информацией о собеседовании)
- Передаётся: только имя (настоящее имя)
- Не передаётся: номер телефона, e-mail, ID в мессенджере, адрес и любые другие контакты
- Цель: проверка личности в день собеседования
- Срок: до окончания этого собеседования
- Связь с работодателями — только через VISA n JOB. Информацию о собеседовании вам также даст сотрудник VISA n JOB.
- Вы можете не соглашаться. Тогда собеседование организуют без вашего имени.
- Вы можете отозвать согласие в любое время на странице «Мой кабинет»; ваше имя сразу исчезнет с экрана работодателя.

## Оригинал на корейском

면접 기업 이름 제공 동의 (면접 건별)

비자앤잡은 면접이 확정된 건마다 따로 동의를 받습니다. 동의하면 그 면접의 해당 기업에만 이름을 알려 줍니다.

- 제공받는 곳: 이 면접을 진행하는 기업 한 곳 (기업 이름은 비자앤잡 담당자가 면접 안내 때 알려 드립니다)
- 제공 항목: 이름(실명)만
- 제공하지 않는 항목: 전화번호, 이메일, 메신저 아이디, 주소 등 연락처 전부
- 목적: 면접 당일 본인 확인
- 기간: 이 면접 건이 끝날 때까지
- 기업과의 연락은 비자앤잡을 통해서만 진행합니다. 면접 안내도 비자앤잡 담당자가 드립니다.
- 동의하지 않아도 됩니다. 동의하지 않으면 이름 없이 면접 일정만 조정합니다.
- 언제든 마이페이지에서 철회할 수 있으며, 철회하면 기업 화면에서 이름이 바로 사라집니다.
